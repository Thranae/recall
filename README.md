## ✨ Features

- **🔎 Instant Deep OCR & Search**: Extract and search every word from screenshots in sub-100ms using on-device and edge OCR.
- **📍 Apple Visual Look-Up & Interactive Pins**: Pinpoint products, landmarks, code snippets, notes, and academic marksheets with precise contextual AI data cards.
- **📁 Smart Auto-Categorization**: Multi-modal Gemini analysis tags screenshots automatically into Chats, Code, Notes, Products, and Documents.
- **🔒 Private & Secure**: Client-side encryption with local caching ensures personal screenshots remain under user sovereignty.
- **📱 Tri-Platform Execution**: Fully responsive web app running on Vercel and hardware-accelerated native Android & iOS via Capacitor 8.

## 🛠️ Development & Build

```bash
# Install dependencies
npm install

# Run Vite development server
npm run dev

# Build client and server bundles
npm run build

# Synchronize Capacitor Android project
npm run cap:sync
```
